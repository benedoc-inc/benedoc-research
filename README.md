# benedoc-research

Companion code and data for BeneDoc's public research on medical device regulation. All analyses derive from public U.S. FDA records.

## Papers

- **[need-for-speed/](need-for-speed/)** — *The Need for Speed: Regulatory Strategies for Fast-Moving AI and Software Medical Devices, and the Rise of the Predetermined Change Control Plan, 2018–2026.* FDA pathway use (510(k), De Novo, PMA, Special) benchmarked across the device population, and a full device-level census of PCCP adoption. Includes `data/pccp_devices.csv` — every PCCP identified, keyed to its public FDA submission number.
